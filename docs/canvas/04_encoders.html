Redwing Quick Reference: Encoders

Setup (before robot.start())

enc = robot.D2.encoder()    # D ports only (D0–D7)
enc.inverted = True         # optional: flip count direction

Reading

enc.count       # total ticks since last reset (whole number)
enc.velocity    # speed in ticks per second (+ forward, - backward)
enc.reset()     # set count back to 0

If count goes down when the motor has a positive power, set enc.inverted = True.

Ticks → distance

TICKS_PER_REV = 537.7    # encoder ticks per WHEEL revolution (check your motor)
WHEEL_DIAM_CM = 9.6

TICKS_PER_CM = TICKS_PER_REV / (3.14159 * WHEEL_DIAM_CM)

distance_cm = enc.count / TICKS_PER_CM

Find TICKS_PER_REV yourself: reset() the encoder, turn the wheel exactly one revolution by hand, and read enc.count. Don't trust a datasheet's "PPR" number, which may be 4× too small.

Example: drive 50 cm, then stop

from redwing import Robot

TICKS_PER_CM = 537.7 / (3.14159 * 9.6)

robot = Robot()
motor = robot.D0.motor()
enc   = robot.D2.encoder()
robot.start()

enc.reset()
target = 50 * TICKS_PER_CM

done = False

while not done:
    # INPUT
    ticks = enc.count
    speed = enc.velocity

    # DECIDE
    power = 50                       # default: keep driving
    if ticks >= target:
        done  = True
        power = 0                    # reached target: stop

    # OUTPUT
    motor.set_power(power)
    robot.log("Ticks:", ticks, " Speed:", speed)

    robot.sleep(0.02)
