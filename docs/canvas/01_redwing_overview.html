Redwing Quick Reference: Setup & Motors

Every program starts like this

from redwing import Robot

robot = Robot()

# 1. Set up devices here (motors, sensors, ...)

robot.start()

# 2. Control code goes here

Rule: set up all devices before robot.start(). Using a device before start() is an error.

Ports

PortUse for
D0–D7DC motors (2-wire driver), encoders, ultrasonic sensors
S0–S7Motor controllers with a servo/PWM input (ESCs), servos

One device per port.

Set up a motor

left  = robot.D0.motor()    # motor driver on a D port
right = robot.D1.motor()
arm   = robot.S0.motor()    # motor controller on an S port

right.inverted = True       # flip direction (no rewiring)

Control a motor

left.set_power(75)     # -100 (full reverse) to 100 (full forward)
left.set_power(-50)    # reverse, half power
left.stop()            # stop one motor
robot.stop()           # stop ALL motors

Waiting & printing

robot.sleep(2)                 # wait 2 seconds
robot.log("Hello", 42)         # print to the dashboard console

Example: drive forward 2 s, then stop

from redwing import Robot

robot = Robot()
left  = robot.D0.motor()
right = robot.D1.motor()
robot.start()

left.set_power(60)
right.set_power(60)
robot.sleep(2)
robot.stop()

Control loop pattern: Input → Decide → Output

while True:
    # INPUT: read every sensor and controller value into variables
    # DECIDE: do calculations and make decisions with those variables
    # OUTPUT: set each motor's power ONCE, at the end

    robot.sleep(0.02)   # always sleep inside loops

Only read inputs in the INPUT section, and only call set_power() in the OUTPUT section.
