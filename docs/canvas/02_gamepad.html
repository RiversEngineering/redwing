Redwing Quick Reference: Gamepad

Setup

gp = robot.gamepad    # no setup needed; works with the dashboard controller or a USB pad

Joysticks (-1.0 to 1.0)

gp.left_x     # -1 = left,  1 = right
gp.left_y     # -1 = back,  1 = forward
gp.right_x
gp.right_y

Throttle & turn

Throttle = forward/back. Turn = rotation. Save stick readings in named variables first, then pass the variables to set_power().

throttle = gp.left_y * 100    # scale -1..1 to -100..100
turn     = gp.right_x * 100

left_power  = throttle + turn
right_power = throttle - turn

left.set_power(left_power)
right.set_power(right_power)

Buttons

Held down (True every loop)Just pressed (True once per press)
gp.a gp.b gp.x gp.ygp.just_pressed_a (etc.)
gp.dpad_up gp.dpad_down gp.dpad_left gp.dpad_rightgp.just_pressed_dpad_up (etc.)
gp.lb gp.rb (bumpers)gp.just_pressed_lb / gp.just_pressed_rb
  • Held → continuous actions (turbo, intake).
  • Just pressed → one-time actions (toggle a mode).

Read each just_pressed_ value once per loop into a variable. It's True only the first time you check it after a press.

Triggers (0.0 to 1.0)

gp.lt   gp.rt                              # how far pressed
gp.just_pressed_lt   gp.just_pressed_rt    # once per press

Connected?

gp.connected    # True if a controller is active

Example: drive + buttons

from redwing import Robot

robot = Robot()
left   = robot.D0.motor()
right  = robot.D1.motor()
intake = robot.D2.motor()
gp = robot.gamepad
robot.start()

while True:
    # INPUT
    throttle    = gp.left_y * 50     # half speed by default
    turn        = gp.right_x * 50
    turbo_held  = gp.rb
    intake_held = gp.a

    # DECIDE
    if turbo_held:                   # hold RB for full speed
        throttle = throttle * 2
        turn     = turn * 2

    left_power  = throttle + turn
    right_power = throttle - turn

    intake_power = 0                 # default: intake off
    if intake_held:
        intake_power = 80

    # OUTPUT
    left.set_power(left_power)
    right.set_power(right_power)
    intake.set_power(intake_power)

    robot.sleep(0.02)
