Redwing Quick Reference: Distance Sensors

SensorRangePortSetup (before robot.start())
Ultrasonic (RCWL-1601)2 cm – 4 mD0–D7us = robot.D2.ultrasonic()
Time-of-flight (VL53L0X)3 cm – 2 mI²C (auto-detected)tof = robot.vl53l0x()
TF Luna LiDAR20 cm – 8 mD7 (default) or D6luna = robot.tfluna() (D7)
luna = robot.tfluna(port=14) (D6)

Reading (same for every sensor)

us.distance       # centimeters, -1 if invalid
us.distance_mm    # millimeters, -1 if invalid
us.valid          # True if the reading can be trusted

tof.distance      # same properties: tof.distance_mm, tof.valid, tof.in_range
luna.distance     # same properties, plus luna.distance_m (meters)

Always check valid first. An invalid reading is -1, which is less than any distance, so if us.distance < 20 is True when nothing is there.

Example: stop when close

from redwing import Robot

robot = Robot()
left  = robot.D0.motor()
right = robot.D1.motor()
us    = robot.D2.ultrasonic()
robot.start()

while True:
    # INPUT
    distance = us.distance
    valid    = us.valid

    # DECIDE
    power = 50                       # default: drive
    if valid and distance < 20:
        power = 0                    # something close: stop

    # OUTPUT
    left.set_power(power)
    right.set_power(power)
    robot.log("Distance:", distance)

    robot.sleep(0.05)
