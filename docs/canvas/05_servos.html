Redwing Quick Reference: Servos

Setup (before robot.start())

arm = robot.S0.servo()    # S ports only (S0–S7), 0–300° range

# standard 180° hobby servo:
arm = robot.S0.servo(max_deg=180, min_us=1000, max_us=2000)

Use S0–S4 freely. S5, S6, S7 can't be used as servos if there's a motor on D2, D3, D7 (respectively).

Moving (after robot.start())

arm.set_angle(90)    # move to 90° (clamped to the servo's range)
arm.center()         # move to the middle of the range
arm.angle            # last angle you commanded (read-only)

A servo has no position sensor you can read. arm.angle is what you asked for, not where the servo actually is.

GoBilda continuous rotation

arm.set_gobilda_mode('continuous')   # once, after robot.start()
arm.set_angle(50)     # half speed forward (-100 to 100)
arm.set_angle(0)      # stop

arm.set_gobilda_mode('positional')   # back to 0–300°

Example: hold A to close the claw

from redwing import Robot

robot = Robot()
claw  = robot.S0.servo()
gp    = robot.gamepad
robot.start()

while True:
    # INPUT
    pressed = gp.a

    # DECIDE
    angle = 100              # default: open
    if pressed:
        angle = 200          # A held: closed

    # OUTPUT
    claw.set_angle(angle)

    robot.sleep(0.02)
