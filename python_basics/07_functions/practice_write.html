Assignment 7 Practice: Write It Yourself

⏱ Estimated time: 40 minutes Prerequisite: Assignment 7 — Functions

Time to write functions from scratch instead of just reading or fixing them. Each problem below gives you a spec in plain English — you decide how to turn it into working Python. Every function already has test calls with print() waiting below it, so you'll know immediately whether your answer is right.

What you'll practice
  • Turning a plain-English spec into a def with the right parameters and a return
  • Reusing conditionals and loops from earlier modules inside a function
  • Looping over the characters of a string, just like looping over a list
  • Combining a loop and an accumulator to reduce a list down to one number
  • Writing a general-purpose version of logic you've seen written one-off before

How to use this file

Open practice_write.py. Every function currently just has pass in its body — a placeholder keyword that means "do nothing," so the file runs without crashing but every test prints None. Replace pass with real code, one function at a time, running python3 practice_write.py after each one to check your progress.

💡 Tip
Write the return line first — even a simple, possibly wrong one — and run the file to make sure the function is being called correctly and something prints. Only after that basic wiring works should you go back and add the real logic. It's much easier to debug one small piece at a time than to write ten lines and then wonder why nothing works.

Problem 1 — is_even(n)

Write def is_even(n): that returns True if n is even, and False if it's odd.

Problem 2 — celsius_to_fahrenheit(c)

Write def celsius_to_fahrenheit(c): that converts and returns a Fahrenheit temperature. Formula: F = C * 9 / 5 + 32. You may have written this exact math back in an earlier module — this time, package it into a reusable function.

CallReturns
celsius_to_fahrenheit(0)32.0
celsius_to_fahrenheit(100)212.0
celsius_to_fahrenheit(37)98.6

Problem 3 — max_of_three(a, b, c)

Write def max_of_three(a, b, c): that returns whichever of the three numbers is largest. Do not use Python's built-in max() — use if/elif/else comparisons, the same tool you already used for this kind of problem before functions existed — now generalized into something reusable.

CallReturns
max_of_three(3, 7, 5)7
max_of_three(10, 2, 9)10
max_of_three(-1, -5, -3)-1

Problem 4 — count_letter(word, letter)

Write def count_letter(word, letter): that returns how many times letter appears inside word. You can loop over the characters of a string the exact same way you loop over a list: for ch in word:. A string is just a sequence of characters, so this is a natural extension of the for loops you already know.

CallReturns
count_letter("banana", "a")3
count_letter("mississippi", "s")4

Problem 5 — average_of_list(numbers)

Write def average_of_list(numbers): that takes a list and returns the average of its values. Use a loop with an accumulator to add everything up (like you did in Module 6), then divide by len(numbers).

CallReturns
average_of_list([10, 20, 30])20.0
average_of_list([5, 15, 25, 35])20.0

Problem 6 — clamp(value, low, high)

Write def clamp(value, low, high): — a general-purpose version of the core lesson's clamp_power, but not locked to the -100/100 range. Return low if value is less than low, high if value is greater than high, and value unchanged otherwise.

CallReturns
clamp(150, 0, 100)100
clamp(-10, 0, 100)0
clamp(50, 0, 100)50

Problem 7 — calculate(a, b, operation)

Write def calculate(a, b, operation): — a mini calculator. operation is a string: "+", "-", "*", or "/". Use if/elif/else to compare operation against each symbol and return the matching result. This one pulls together everything from this module — functions, conditionals, strings, and arithmetic — into one small program.

CallReturns
calculate(6, 3, "+")9
calculate(6, 3, "-")3
calculate(6, 3, "*")18
calculate(6, 3, "/")2.0
