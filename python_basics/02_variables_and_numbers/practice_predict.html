Assignment 2 Practice: Predict the Output

⏱ Estimated time: 25 minutes Prerequisite: Assignment 2 — Variables & Numbers

Reading code and predicting what it will do — before you run it — is one of the fastest ways to build a real mental model of a language. Below are 8 short snippets pulled straight from the concepts in Assignment 2. For each one, write down your prediction first, then open practice_predict.py and run it with python3 practice_predict.py to see if you were right.

What you'll practice
  • Tracing variable assignment and reassignment by hand
  • Operator precedence (order of operations)
  • The difference between /, //, and %
  • Predicting whether a result is an int or a float
💡 How the reveal boxes work
Each snippet below has a gray box showing the correct answer. It's hidden on purpose — the pixel color is the same as the background, so it looks blank. Drag-select across it (or double-click it) to highlight the text and reveal the answer. Make your prediction first, then reveal it to check.

Prediction 1 — assignment

x = 5
print(x)

Prediction: 5

Prediction 2 — reassignment

x = 5
x = 10
print(x)

Prediction: 10

The first assignment is completely overwritten — Python doesn't remember that x was ever 5.

Prediction 3 — precedence

print(2 + 3 * 4)

Prediction: 14 (not 20 — multiplication happens before addition)

Prediction 4 — true division vs. floor division

print(7 / 2)
print(7 // 2)

7 / 2 prediction: 3.5

7 // 2 prediction: 3

Prediction 5 — modulo

print(10 % 3)

Prediction: 1

Prediction 6 — exponent

print(2 ** 10)

Prediction: 1024

Prediction 7 — chained +=

x = 5
x += 3
x += 2
print(x)

Prediction: 10

Prediction 8 — mixed int/float

print(5 + 2.0)

Prediction: 7.0 — a float, even though it looks like a whole number.

⚠️ Common mistake
Predicting 7 instead of 7.0 for Prediction 8. If any number involved in an arithmetic operation is a float, the result is a float, even if the decimal part happens to be .0.

Check Yourself

  • Why does int + float give a float result, even when that result has no fractional part?
  • In Prediction 7, why does x end up as 10 instead of just 5? Walk through each += step by step.
