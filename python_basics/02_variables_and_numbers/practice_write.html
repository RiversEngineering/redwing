Assignment 2 Practice: Write It Yourself

⏱ Estimated time: 40 minutes Prerequisite: Assignment 2 — Variables & Numbers

No scaffolding this time — practice_write.py gives you the starting values for each problem and a plain-English description of what to compute. Write the code yourself, from scratch, using only variables, arithmetic, and print(). Check each answer against the expected output listed below before moving on.

What you'll practice
  • Turning a plain-English formula into Python arithmetic
  • Choosing the right operator: /, //, %, **
  • Using += to update a variable and recompute from it
  • Printing labeled results with comma-separated print()
💡 Tip
When you translate a formula from math into Python, add parentheses around anything that should be grouped together, even if you think Python would get it right anyway — for example (score1 + score2 + score3) / 3 instead of score1 + score2 + score3 / 3. It costs you nothing and saves you from the exact precedence bug you fixed in Debug It.

Problem 1 — circle measurements

Given radius = 4, compute and print the circle's area (area = pi * radius ** 2) and its circumference (circumference = 2 * pi * radius). Use 3.14159 for pi. Expected output:

Area: 50.26544
Circumference: 25.13272

Problem 2 — minutes to hours and minutes

Given total_minutes = 137, compute and print how many whole hours and how many leftover minutes that is, using // and %. Expected output:

Hours: 2
Leftover minutes: 17

Problem 3 — price with tax

Given price = 19.99 and tax_rate = 0.08, compute and print the total cost including tax (price + price * tax_rate). Expected output:

Total cost: 21.589199999999998

(Yes, that trailing string of 9s and 8s is correct — that's how computers store floats. It's not a bug in your code.)

Problem 4 — average of three scores

Given score1 = 88, score2 = 92, score3 = 79, compute and print their average. Expected output:

Average score: 86.33333333333333

Problem 5 — Celsius to Fahrenheit

Given celsius = 23, convert to Fahrenheit using F = C * 9 / 5 + 32 and print it. Expected output:

Fahrenheit: 73.4

Problem 6 — distance with a speed boost

Given speed = 45 and time = 2, compute and print the distance traveled (distance = speed * time). Then use speed += 15 to simulate a speed boost, recompute the distance for the new speed over the same time, and print that too. Expected output:

Distance: 90
New distance: 120

Problem 7 — change due

Given cost = 12.50 and amount_paid = 20, compute and print the change due. Expected output:

Change due: 7.5
