Variables: named boxes for values

A variable is a name that stores a value so you can use it later. You create one with an assignment statement: a name, an equals sign, and a value.

battery_voltage = 11.1
print(battery_voltage)

This does two things: it stores the value 11.1 in a box labeled battery_voltage, and from then on you can use battery_voltage anywhere you'd otherwise write 11.1.

💡 Tip
In math, = means "these two things are equal." In Python it means something different: "store the thing on the right into the name on the left." That's why x = x + 1 makes perfect sense in Python (it updates the box) even though it would be nonsense as a math equation.

Naming rules — a variable name:

  • can only contain letters, numbers, and underscores (_)
  • can't start with a number (2fast is invalid, fast2 is fine)
  • is case-sensitive — Speed and speed are two different variables

By convention, Python names use snake_case: lowercase words separated by underscores, like battery_voltage rather than BatteryVoltage. Use descriptive names — battery_voltage instead of bv. Six months from now (or six minutes from now, debugging your robot), you'll thank yourself.

Two kinds of numbers

Python has two number types you'll use constantly:

  • int — a whole number, like 3 or -12. No decimal point.
  • float — a number with a decimal point, like 3.7 or -0.5.

A battery cell count (3) is naturally an int — you can't have half a cell. A cell's voltage (3.7) is a float.

Arithmetic operators

Python can do all the arithmetic you'd expect, plus two operators that might be new to you:

print(7 + 2)    # 9   addition
print(7 - 2)    # 5   subtraction
print(7 * 2)    # 14  multiplication
print(7 / 2)    # 3.5 division — always gives a float, even if it divides evenly
print(7 // 2)   # 3   floor division — divides, then drops anything after the decimal
print(7 % 2)    # 1   modulo — the remainder left over after division
print(7 ** 2)   # 49  exponent — 7 to the power of 2

// and % are useful together: if total_seconds = 125, then total_seconds // 60 gives the whole minutes (2) and total_seconds % 60 gives the leftover seconds (5).

Order of operations

Python follows the same order of operations you learned in math class (often remembered as PEMDAS): parentheses first, then exponents, then multiplication/division, then addition/subtraction, left to right. When in doubt, add parentheses () to say exactly what you mean.

print(2 + 3 * 4)     # 14  -> multiplication happens before addition
print((2 + 3) * 4)   # 20  -> parentheses force the addition first
⚠️ Common mistake
Writing average = a + b + c / 3 to compute an average of three numbers. Python does the division first (c / 3), then adds a and b — not what you wanted. The fix is average = (a + b + c) / 3, which adds everything first, then divides.

Updating a variable with its own value

A variable can be updated using its own current value. This is one of the most common patterns in programming — you'll use it constantly for things like counting, accumulating, or nudging a motor's power up or down.

motor_power = 45
motor_power = motor_power + 15   # read the old value, add 15, store the new value
print(motor_power)               # 60

Python has a shorthand for this that you'll see everywhere: motor_power += 15 does exactly the same thing as motor_power = motor_power + 15. There are matching shorthands for subtraction and multiplication: -= and *=.
