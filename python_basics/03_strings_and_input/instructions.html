That's the first step toward a robot that reacts to the world instead of just running a fixed script.

What you'll learn

1. Joining strings with +

You already know strings from Lesson 1 — text inside quotes. You can join ("concatenate") two strings with +:

greeting = "Hello, " + "world!"
print(greeting)          # Hello, world!

But + only works between two strings. Try to + a string and a number and Python refuses:

print("Power level: " + 100)
# TypeError: can only concatenate str (not "int") to str

Python won't guess whether you meant to glue the number's digits onto the text or add it as a number — it just stops with an error. The fix is either to convert the number to a string first with str(), or — better — use an f-string, which you'll meet next.

2. f-strings: a cleaner way to build text

In Lesson 2 you printed mixed text and numbers with the comma trick: print(a, "text", b). It works, but Python inserts spaces for you and you can't control the wording as closely. An f-string lets you write the sentence exactly as you want it and drop variables straight into the middle of it using curly braces { }:

name = "Ada"
speed = 42
print(f"Hello, {name}! Top speed is {speed} percent.")
# Hello, Ada! Top speed is 42 percent.

The f right before the opening quote is what turns on this behavior — without it, {name} would just print literally as the text {name}. Notice speed is a number, and Python converted it to text automatically — no str() needed inside an f-string. You can even put a whole expression inside the braces:

a = 6
b = 7
print(f"{a} times {b} is {a * b}")
# 6 times 7 is 42

You can also measure a string with the built-in function len(), which counts its characters (letters, digits, spaces — everything counts):

team = "Redwing"
print(len(team))    # 7
💡 Tip
f-strings are the modern, cleaner replacement for the comma-print trick from Lesson 2. Whenever you find yourself building a sentence out of several + or commas, reach for an f-string instead.

3. input(): asking the user a question

The function input("prompt: ") pauses your program, prints the prompt text, and waits for the person running the program to type something and press Enter. Whatever they typed comes back as the result:

name = input("What's your name? ")
print(f"Hello, {name}!")

Run that, type Ada, hit Enter, and you'll see Hello, Ada!. Critically: no matter what the person types — even if they type 16 — input() always hands it back as a string, never a number.

4. Converting input into a number

Because input() always returns text, if you want to do math with what the user typed you must convert it first, using int() for whole numbers or float() for decimals:

age = int(input("How old are you? "))
age_in_months = age * 12
print(f"You are about {age_in_months} months old.")

The conversion happens right around the input() call: Python reads the text, hands it to int(), and only then stores the result in age.

⚠️ Common mistake
Forgetting to convert. If you write age = input("How old are you? ") without int(), then age is still text. Typing age * 12 doesn't crash — but it doesn't multiply either. Multiplying a string by a number repeats the string that many times, so "16" * 12 gives you "161616161616161616161616" — a wall of digits, not the number 192. If your math output looks like nonsense, check whether you forgot to convert the input first. And if you instead try age + 12 on un-converted text, that does crash with a TypeError, same as adding a string and a number anywhere else.
