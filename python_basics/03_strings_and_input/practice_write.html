Assignment 3 Practice: Write It Yourself

⏱ Estimated time: 40 minutes Prerequisite: Assignment 3 — Strings & Input

No fill-in-the-blank this time. practice_write.py gives you seven problems, each with its own starting variables and a # Write your code here placeholder — the rest is up to you. Match the expected output listed below for each problem; your exact code doesn't have to match anyone else's as long as the output does.

What you'll practice
  • Writing f-strings from scratch instead of filling in a blank
  • Combining + and f-strings in the same program
  • Using len() and arithmetic inside a message you design yourself
  • Deciding how to word output so it reads like a real sentence

Problem 1 — welcome message

Given:

team_name = "Redwing Robotics"

Print a welcome sentence with an f-string that also includes len(team_name). Expected output:

Welcome, Redwing Robotics! Your team name has 16 characters.

Problem 2 — sum, difference, product

Given:

first_num = 12
second_num = 7

Print the sum, difference, and product, each on its own line with a labeled f-string. Expected output:

Sum: 19
Difference: 5
Product: 84

Problem 3 — build a badge

Given:

team_name = "Redwing"
robot_number = 3

Combine them into a "badge" string like "Redwing-3" using concatenation and/or an f-string, print it, then print its length with len(). Expected output:

Redwing-3
9

Problem 4 — Celsius to Fahrenheit

Given:

celsius = 100.0

Convert to Fahrenheit using F = C * 9 / 5 + 32 and print the result with an f-string. Expected output:

100.0°C is 212.0°F

Problem 5 — total minutes

Given:

hours = 2
minutes = 45

Compute the total number of minutes and print it with an f-string. Expected output:

2 hours and 45 minutes is 165 minutes total.

Problem 6 — decorate a sentence

Given:

sentence = "Robots are awesome"

Print it wrapped in decoration using an f-string (e.g. f"*** {sentence} ***"), then print its length. Expected output:

*** Robots are awesome ***
18

Problem 7 — mad libs

Given:

noun = "gear"
verb = "spins"
number = 7

Build and print a silly sentence combining all three, with number * 2 embedded via f-string. Expected output:

The gear spins 14 times before breakfast!
💡 Tip
When should you reach for + instead of an f-string? Plain concatenation reads fine for gluing two or three short pieces together, like a badge in Problem 3. But once you're mixing in numbers, punctuation, or more than a couple of pieces, an f-string is almost always easier to read and less error-prone — you write the sentence exactly as it should look and just drop values into { } where they belong.

Quick Reference

SyntaxWhat it does
f"{x}"Drops the value of x (or any expression, like number * 2) directly into text.
"a" + "b"Joins two strings end to end — good for short, simple combos like a badge.
len(text)Number of characters in a string.
a * bOrdinary multiplication when both sides are numbers.
