Assignment 3 Practice: Debug It

⏱ Estimated time: 30 minutes Prerequisite: Assignment 3 — Strings & Input

practice_debug.py contains seven bugs. Some of them would crash the program outright, so those are left commented out — your job is to read the code and work out what error they'd raise and why, before you uncomment and fix anything. The rest are "silent" bugs: the code runs just fine, but it prints the wrong thing, so those are left live and running right now. Fix each bug, then run the file again to confirm every line prints what it was supposed to.

What you'll practice
  • Recognizing TypeError, SyntaxError, and NameError by sight
  • Telling the difference between a crash and a silent wrong-output bug
  • Fixing missing conversions (int()), missing braces, typo'd variable names, and missing spaces
  • Reading a Python traceback to find the fix

Bug 1 — string + int

# print("Power level: " + 100)

Error type: TypeError — + can't join a string and an int directly. Corrected expected output:

Power level: 100

Bug 2 — forgot to convert before adding

# count = "5"
# total = count + 3
# print(total)

Error type: TypeError — count is still text, so count + 3 tries to add text and a number. Corrected expected output:

8

Bug 3 — two numeric-looking strings (live, no crash)

qty = "5"
more = "3"
print(qty + more)

This one doesn't crash. As shipped it prints 53 — the two strings glued together — instead of adding them like numbers. Corrected expected output:

8

Bug 4 — missing closing brace

# name = "Ada"
# print(f"Hello, {name!")

Error type: SyntaxError — the {name is never closed with a matching }. Corrected expected output:

Hello, Ada!

Bug 5 — typo'd variable name

# robot_name = "Titan"
# print(f"Robot name: {robot_nam}")

Error type: NameError — robot_nam was never defined, only robot_name was. Corrected expected output:

Robot name: Titan

Bug 6 — len() on an int

# score = 42
# print(len(score))

Error type: TypeError — len() only works on strings (and a few other sequence types), not plain integers. Corrected expected output (wrap the number in str() first so len() can count its digits):

2

Bug 7 — missing space (live, no crash)

first_word = "Hello"
second_word = "World"
print(first_word + second_word)

No crash here either — but as shipped it prints HelloWorld jammed together, because + never adds a space for you. Corrected expected output:

Hello World
💡 Tip
When Python raises a TypeError, read the last line of the traceback first — it names the exact types involved, e.g. can only concatenate str (not "int") to str. That tells you which variable is the wrong type before you even look at the line number — usually the fix is either wrapping the number in str(), wrapping the text in int()/float(), or switching to an f-string entirely.
