Assignment 1 Practice: Predict the Output

⏱ Estimated time: 20 minutes Prerequisite: Assignment 1 — Hello, Python

This set is pure code-tracing — no editing, no fixing. For each snippet below, read the code first and write down what you think it will print. Do this before you run anything. Then run python3 practice_predict.py and compare your guess to the real output.

Answers are hidden with a highlight-to-reveal trick — drag-select or double-click the gray box to read it. Try to make your own prediction before revealing the answer!

What you'll practice
  • Tracing code top to bottom without running it first
  • Recognizing that comments produce no output
  • Noticing what print() does with no arguments, and when a line is commented out
  • Reading exact-case text and quote characters carefully

Prediction 1

Two print() calls, one after another. What order do they appear on screen?

print("Booting up...")
print("Systems online.")

My prediction: Booting up...
Systems online.

Prediction 2

There's a comment line right before the print(). Does it produce any visible output?

# This line is just a note for humans — it won't show up when the program runs
print("Sensors calibrated.")

My prediction: Sensors calibrated.

Prediction 3

A print() call with nothing inside the parentheses sits between two other prints. What happens?

print("Left motor: OK")
print()
print("Right motor: OK")

My prediction: Left motor: OK
 
Right motor: OK (there's a blank line in the middle)

Prediction 4

The first print() line below is commented out. Does any part of it appear in the output?

# print("Overheating!")
print("Temperature normal.")

My prediction: Temperature normal. (the commented-out line never runs, so "Overheating!" never appears)

Check Yourself
