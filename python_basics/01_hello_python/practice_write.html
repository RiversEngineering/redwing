Assignment 1 Practice: Write It Yourself

⏱ Estimated time: 35 minutes Prerequisite: Assignment 1 — Hello, Python

This set is about writing code from scratch. practice_write.py has 6 numbered problems, each described in a comment with a # Write your code here placeholder underneath. Unlike the core lesson, there's no partial code to fill in — you're writing every print() statement yourself. Stick to print(), comments, and string literals — no variables yet (that's Module 2).

What you'll practice
  • Writing your own print() statements from a plain-English description
  • Matching an exact target output, line for line
  • Writing a clear, helpful comment
  • Choosing single vs. double quotes when your text itself contains a quote character
  • Putting multiple statements in the correct order

Problem 1

Print your name and your grade level on two separate lines — one print() call for each.

For example, if your name is Alex and you're in 10th grade, your output should look like:

Alex
10th grade

Problem 2

Print a 3-line "robot status report", each on its own line, exactly as follows:

Power: ON
Sensors: Ready
Mode: Standby

Problem 3

Print a small triangle made of asterisks using 3 separate print() calls — one line each, literal strings, no loops needed:

*
**
***

Problem 4

The line print("Connecting to robot base station.") is already there for you. Add ONE comment directly above it, explaining in your own words what that line does.

There's no single right answer here (so no expected output to check against) — but a good comment is short, plain, and describes the purpose of the line rather than just repeating the code. Something like # Tells the program to connect to the robot's base station is on the right track.

Problem 5

Print the sentence It's launch day! exactly as written. This one takes a bit of care with quote characters, since the sentence itself contains an apostrophe.

It's launch day!
💡 Tip
If the text you want to print contains an apostrophe (like It's), wrap the whole string in double quotes instead of single quotes: print("It's launch day!"). If you used single quotes instead, Python would think the apostrophe was the closing quote, and the rest of the line would confuse it.

Problem 6

Write two print() statements, in the correct order, that tell this 2-step story: first announce "Starting engine check...", then announce "All systems go!"

Starting engine check...
All systems go!

Quick Reference

SyntaxMeaning
print("text")Displays the text on the screen
# a noteA comment — ignored by Python, for humans only
"..." or '...'Marks the start and end of a string of text
"It's ..."Use double quotes on the outside when the text itself contains an apostrophe
Order of statementsEach print() runs top to bottom, in the order it's written
