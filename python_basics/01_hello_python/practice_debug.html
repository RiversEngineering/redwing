Assignment 1 Practice: Debug It

⏱ Estimated time: 25 minutes Prerequisite: Assignment 1 — Hello, Python

This set is about finding and fixing bugs. practice_debug.py contains 6 numbered bugs. Five of them would crash the program (a SyntaxError or NameError) if you ran them as written, so they're shown commented out — every line starts with # — so the distributed file always runs cleanly with zero errors. One bug (Bug 6) doesn't crash anything; it's a logic bug — the code runs fine but produces the wrong output — so it's left active for you to actually see it misbehave.

What you'll practice
  • Recognizing a SyntaxError vs. a NameError
  • Spotting missing, extra, or mismatched quote characters
  • Noticing when a comment is missing its leading #
  • Telling a crash bug apart from a logic bug (wrong order, no crash)

Bug 1

print("Battery check passed)

Error type: SyntaxError — unterminated string literal. The closing quote is missing.

Corrected output:

Battery check passed

Bug 2

print "Motors connected"

Error type: SyntaxError — missing parentheses in call to print. This is old Python 2 style — Python 3 always requires parentheses.

Corrected output:

Motors connected

Bug 3

print("Sensors online')

Error type: SyntaxError — the opening quote is a double quote " but the closing quote is a single quote '. They don't match, so Python can't tell where the string ends.

Corrected output:

Sensors online

Bug 4

Print("Camera ready")

Error type: NameError — name 'Print' is not defined. Python is case-sensitive — only lowercase print is a real command.

Corrected output:

Camera ready

Bug 5

This line was meant to be a plain comment reminding the team to check the wiring — but as originally written, it was missing its leading #:

Check the wiring before powering on

Error type: SyntaxError — invalid syntax. Without the #, Python tries to run those English words as a statement, and it isn't valid Python.

Corrected output: nothing is printed at all — once the # is restored, it's a proper comment and Python skips it entirely.

Bug 6 (logic bug — no crash)

print("Engine check complete.")
print("Engine check starting...")

What's wrong: this runs without any error, but the two lines are in the wrong order — the engine is announced "complete" before it even starts checking. The fix is simply to swap the two lines.

Corrected output:

Engine check starting...
Engine check complete.
⚠️ Common mistake
When Python shows you an error, read the message itself, not just the line number — it usually names the exact problem (missing quote, wrong parentheses, unknown name) and points at or very near where it happened. Beginners often panic and rewrite the whole line; instead, read the last line of the error first, then look at the arrow or line number it gives you.

Quick Reference

Error typeWhat it means
SyntaxErrorYou broke a grammar rule of the Python language — a missing quote, a mismatched quote, a missing parenthesis, or code where a comment should be
NameErrorYou used a name Python doesn't recognize, often from a typo or wrong capitalization
Logic bugThe code runs with no error at all, but does the wrong thing — like printing lines in the wrong order
