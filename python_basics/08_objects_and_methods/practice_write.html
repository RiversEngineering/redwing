Assignment 8 Practice: Write It Yourself

⏱ Estimated time: 45 minutes Prerequisite: Assignment 8 — Objects & Methods

Seven problems, no fill-in-the-blank this time — each one gives you starting variables in practice_write.py and a # Write your code here placeholder. Write the lines yourself, run the file, and compare your output to the expected output listed below for each problem. The last one is a capstone that pulls together everything from all 8 modules — no hardware required, just the terminal.

What you'll practice
  • Combining .strip() with len()
  • Building a list from scratch with repeated .append() calls, then .sort()
  • Three brand-new (but intuitive) string methods: .count(), .replace(), .split()
  • Chaining two methods together in a single line
  • Capstone: combining for and if/elif/else to simulate a robot reacting to sensor data
💡 Tip
When you chain two methods together, like text.strip().upper(), read it left to right: the first method runs on the original value, and the second one runs on whatever the first one just returned. Nothing runs "at the same time" — it's a straight line of one step after another, just written compactly.
