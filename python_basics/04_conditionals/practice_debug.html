if Practice: Debug It

Not every bug crashes your program. Some bugs are loud — Python refuses to run at all and shows you an error message. Others are quiet — the code runs just fine and prints something, it's just wrong, and nothing tells you that. Both kinds show up in practice_debug.py in this folder. Your job is to find and fix all 7.

What you'll practice
  • Recognizing SyntaxError, IndentationError, and TypeError by what triggers them
  • Catching a wrong and/or that never fires the branch it should
  • Catching elif branches made unreachable ("dead code") by their own ordering
  • Catching off-by-one boundary bugs (< where <= was meant)

The crash-bugs (1, 2, 3, and 7 below) are shipped fully commented out in practice_debug.py — that's the only reason the file runs at all as distributed. The logic-only bugs (4, 5, and 6) are live: the file runs, but prints the wrong thing for each of them.

Bug 1

# Goal: print "Threshold reached" when x is exactly 10.
x = 10
if x = 10:
    print("Threshold reached")

Bug 2

# Goal: print "Motor cool" when motor_temp_c is 40 or below.
motor_temp_c = 35
if motor_temp_c <= 40
    print("Motor cool")

Bug 3

# Goal: print "Sensor error" if reading is negative, otherwise print
# the reading itself.
reading = -5
if reading < 0:
    print("Sensor error")
else:
print(reading)
💡 Tip
Every line inside the same block must be indented by the exact same amount. Python doesn't care whether you use 2 spaces or 4, as long as you're consistent within a block and your editor isn't secretly mixing tabs and spaces. If you ever see IndentationError: expected an indented block, look at the line right after your colon first.
⚠️ Common mistake
Bugs 4, 5, and 6 are the sneakiest kind: Python never complains, the program runs top to bottom, and it prints a real, well-formed answer — it's just the wrong one. A crash at least tells you where to look. A silent logic bug only shows up when you (or someone else) compares the output against what it should have been, which is exactly why testing your conditions against more than one input matters.

Bug 4

# Goal: sound the alarm if the temperature is too low (under 32) OR
# too high (over 100).
temperature = 105
if temperature < 32 and temperature > 100:
    print("ALARM: temperature out of safe range")
else:
    print("Temperature normal")

Bug 5

# Goal: give a discount tier based on order_total:
#   under $10  -> "Tiny order discount"
#   under $100 -> "Standard discount"
#   otherwise  -> "No discount"
order_total = 5
if order_total < 100:
    print("Standard discount")
elif order_total < 10:
    print("Tiny order discount")
else:
    print("No discount")

Bug 6

# Goal: any speed of 60 or below (that's <= 60) counts as "Safe speed".
speed = 60
if speed < 60:
    print("Safe speed")
else:
    print("Too fast")

Bug 7

# Goal: print "Old enough" if age_text (typed in by a user, so it
# starts out as a string) represents an age of 18 or older.
age_text = "20"
if age_text >= 18:
    print("Old enough")
else:
    print("Not old enough")
