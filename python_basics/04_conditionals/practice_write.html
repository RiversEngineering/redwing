Assignment 4 Practice: Write It Yourself

⏱ Estimated time: 40 minutes Prerequisite: Assignment 4 — Making Decisions with Conditionals

Reading someone else's if statements is one skill. Turning a plain-English description into your own working conditional, starting from a blank line, is a different and harder one — and it's the one you'll actually need when you start programming the robot yourself. This set is 7 problems, each starting from nothing but the given variables.

What you'll practice
  • Turning a written rule into an if / elif / else chain from scratch
  • Choosing the right comparison operator for a rule (inclusive vs. exclusive boundaries)
  • Combining two conditions yourself with and / or
  • Comparing multiple variables against each other, not just against a fixed number

How to use this page

Open practice_write.py in this folder. Each problem gives you the input variable(s) already set and a # Write your code here line — replace that line with your own code. The file runs without crashing before you've written anything (an unsolved problem is just a comment), so you can tackle the 7 problems in any order and test as you go.

Problem 1 — battery charge check

Given: battery_voltage = 10.8

Print "Charge now" if the voltage is below 11.0, otherwise print "OK".

Expected output: Charge now

Problem 2 — letter grade

Given: score = 84

Print a letter grade using these thresholds:

scoregrade
90 or above"A"
80 or above"B"
70 or above"C"
60 or above"D"
below 60"F"

Expected output: B

Problem 3 — which way is the robot turning?

Given: left_speed = 40, right_speed = 65

A robot with independent left and right wheel motors curves toward whichever side is spinning slower. Print "Turning left" if the right wheel is faster, "Turning right" if the left wheel is faster, or "Driving straight" if they're equal.

Expected output: Turning left (right_speed is faster)

Problem 4 — safe operating range

Given: temperature = 55

Print "Safe operating range" if the temperature is between 32 and 100, inclusive of both ends, otherwise print "Warning". This needs two comparisons joined with and.

Expected output: Safe operating range

Problem 5 — even or odd

Given: number = 17

Use the % operator (from Module 2) to print "Even" or "Odd". A number is even exactly when dividing it by 2 leaves a remainder of 0.

Expected output: Odd

Problem 6 — largest of three sensor readings

Given: reading_a = 22, reading_b = 41, reading_c = 17

Find and print which one is the largest, using if / elif / else comparisons — no built-in max() allowed. (Hint: for a reading to be the largest, it needs to be greater than or equal to both of the others — that's another and.)

Expected output: The largest reading is B: 41

Problem 7 — emergency halt

Given: emergency_stop = False, battery_critical = True

Print "HALT" if either flag is True, otherwise print "Continue". Use or.

Expected output: HALT

💡 Tip
Before you trust a conditional you just wrote, test it against more than one value in your head — not just the one given to you. For Problem 1, what would your code do with battery_voltage = 11.0 exactly, or 14.0? Mentally trying the boundary value and an obviously-different value is how you catch off-by-one mistakes before they ever reach a real robot.
