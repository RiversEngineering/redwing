Comparison operators

To make a decision, your code first needs to ask a question that has a yes/no answer. Python has six comparison operators for this:

OperatorMeansExample
==equal tox == 10
!=not equal tox != 10
<less thanx < 10
>greater thanx > 10
<=less than or equal tox <= 10
>=greater than or equal tox >= 10

A comparison like distance_cm < 20 doesn't just sit there — it actually produces a value: either True or False. These two special values are called booleans, and you can even store one in a variable, exactly like a number or a string:

distance_cm = 18
is_close = distance_cm < 20
print(is_close)        # True
print(type(is_close))  # <class 'bool'>
⚠️ Common mistake
= and == look similar but do very different jobs. x = 10 assigns 10 to x (sets its value). x == 10 compares — it asks "is x equal to 10?" and never changes anything. Writing if x = 10: by mistake is one of the most common beginner errors in every language that uses this syntax — Python will actually refuse to run it and show a SyntaxError, which is a helpful hint that you meant ==.

The if statement

An if statement runs a block of code only when a condition is True:

distance_cm = 18
if distance_cm < 20:
    print("Too close! Back up.")

Read this as: "if distance_cm is less than 20, print the warning." Since 18 < 20 is True, the indented line runs. If distance_cm had been 30, the condition would be False and that line would simply be skipped.

Indentation is not optional in Python. Every other language you might encounter uses curly braces { } to mark a block of code. Python uses whitespace instead — the indented lines are the block that belongs to the if. The standard is 4 spaces per level. If a line that should be inside the block isn't indented, or is indented by a different amount than its neighbors, Python raises an IndentationError and refuses to run at all.

Adding a fallback: else

What if you want something to happen when the condition is False too? Add an else:

distance_cm = 18
if distance_cm < 20:
    print("Too close! Back up.")
else:
    print("Path is clear.")

Exactly one of these two branches runs — never both, never neither. Notice that else lines up with if (both at the very left), and its own body is indented one level in — just like the if body.

More than two options: elif

Real decisions often have more than two outcomes. elif (short for "else if") lets you chain as many extra checks as you need:

distance_cm = 8
if distance_cm < 10:
    print("STOP")
elif distance_cm < 30:
    print("Slow down")
else:
    print("Full speed ahead")

Python checks these top to bottom and stops at the first condition that's True — the rest are skipped, even if they'd also be true. With distance_cm = 8, the first check 8 < 10 is already True, so "STOP" prints and Python never even looks at the elif. You can chain as many elifs as you like; the final else is optional and catches "none of the above."

Combining conditions: and, or, not

Sometimes one comparison isn't enough. Python's logical operators let you combine multiple conditions into one:

  • and — True only if both sides are True
  • or — True if at least one side is True
  • not — flips a boolean: not True is False
battery_voltage = 11.2
is_low = battery_voltage < 11.5 and battery_voltage > 9.0
if is_low:
    print("Battery low — recharge soon.")
else:
    print("Battery OK.")

This is exactly the shape of that obstacle-avoidance line you saw earlier: if d > 0 and d < 25: means "d is positive AND d is less than 25" — both must be true for the robot to treat it as a real obstacle in range.

💡 Tip
Storing a comparison's result in a variable (like is_low above) is a great habit. It gives your condition a readable name, and you can reuse it in more than one if without retyping the whole comparison.
