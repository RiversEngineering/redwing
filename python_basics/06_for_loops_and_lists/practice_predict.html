Assignment 6 Practice: Predict the Output

⏱ Estimated time: 25 minutes Prerequisite: Assignment 6 — For Loops & Lists

This isn't about writing code — it's about reading it. For each snippet below, look at the code, work out what it will print in your head (or on scratch paper), and only then reveal the answer to check yourself. Being able to trace through a loop without running it is one of the most useful debugging skills you'll build — it's exactly what you'll do when a robot isn't behaving the way you expect and you can't just add a print statement in the moment.

What you'll practice
  • Tracing a for item in a_list: loop step by step
  • Knowing exactly where range() starts and stops
  • Reading positive and negative indices without running the code
  • Tracking what a list looks like after a loop of .append() calls
  • Reasoning about a range() with a custom step

How the reveal works

Every prediction below has a hidden answer that looks like a plain gray box, like this: 42. The text is really there — it's just colored to match its own background, so it's invisible until you reveal it. To check your answer, click just before the box and drag to highlight/select the text (or double/triple-click it) — your browser's selection color will make the text readable. Write down your own prediction before you reveal each one; predicting after peeking doesn't build the skill.

Prediction 1 — looping over a list

temps = [68, 72, 65, 70]
for t in temps:
    print(t)

What gets printed? 68, 72, 65, 70 — each on its own line

Prediction 2 — range(5)

for i in range(5):
    print(i)

What gets printed? 0, 1, 2, 3, 4 — five lines. It stops before 5, it never prints 5.

Prediction 3 — indexing

colors = ["red", "green", "blue", "yellow"]
print(colors[0])
print(colors[-1])

What gets printed? red, then yellow

Prediction 4 — len()

crew = ["Alex", "Sam", "Jordan", "Riley", "Morgan"]
print(len(crew))

What gets printed? 5

Prediction 5 — for + if filtering

scores = [55, 82, 91, 40, 76, 88]
for s in scores:
    if s >= 80:
        print(s)

What gets printed? 82, 91, 88 — only the scores 80 and above, in their original order

Prediction 6 — building a list with append()

doubled = []
for i in range(4):
    doubled.append(i * 2)
print(doubled)

What gets printed? [0, 2, 4, 6]

Prediction 7 — range() with a step

for i in range(2, 10, 3):
    print(i)

What gets printed? 2, 5, 8 — starts at 2, jumps by 3 each time, stops before 10

Prediction 8 — Bonus, we haven't taught this, take a guess!

nums = [10, 20, 30, 40, 50]
print(nums[1:3])

What gets printed? [20, 30] — a "slice" of the list from index 1 up to (not including) index 3

💡 Tip
Notice a pattern: with range(), indexing, and now slicing, the "stop" value is always excluded. range(2, 10, 3) stops before 10, and nums[1:3] stops before index 3. Python is consistent about this everywhere — once it clicks in one place, it clicks everywhere.

Check Yourself

  • In Prediction 7, why doesn't range(2, 10, 3) ever print 11? What's the rule for when a range stops counting?
  • In Prediction 6, why does print(doubled) only run once, after the loop, instead of printing four separate lists?
