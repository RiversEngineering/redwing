Assignment 6 Practice: Write It Yourself

⏱ Estimated time: 40 minutes Prerequisite: Assignment 6 — For Loops & Lists

Seven problems, all from scratch. Each one gives you starting values in practice_write.py and a # Write your code here placeholder — no fill-in-the-blank scaffolding this time, just the goal and the tools you already know. Run python3 practice_write.py after each one to check your output against the expected output listed below.

What you'll practice
  • Looping over a list to transform and print each item
  • Looping by index with range(len(a_list)):
  • Tracking a "best so far" value across a loop
  • Building a list from nothing with .append()
  • Counting items that meet a condition
  • Walking a list backwards with a negative range() step
  • Pairing up two lists by shared index

Problem 1 — double every reading

Given:

readings = [12, 45, 8, 33, 19]

Print each reading doubled, one per line. Expected output:

24
90
16
66
38

Problem 2 — numbered list

Given:

names = ["Ada", "Grace", "Katherine"]

Print each name with its position number, starting at 1, using for i in range(len(names)):. Expected output:

1: Ada
2: Grace
3: Katherine

Problem 3 — find the maximum without max()

Given:

values = [14, 82, 3, 47, 65, 21]

Find and print the maximum value using a loop, a "best so far" variable, and an if comparison — no max() allowed. Start best at the first value, then update it whenever you find something bigger. Expected output:

82

Problem 4 — build a list of squares

Given:

squares = []

Using range() and .append(), build the squares of every number from 1 to 10, then print the final list. Expected output:

[1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

Problem 5 — count above a threshold

Given:

distances = [12, 34, 8, 55, 19, 41]
threshold = 20

Using a loop, an if, and a counter variable, count and print how many distances are above the threshold. Expected output:

Above threshold: 3

Problem 6 — print in reverse

Given:

crew = ["Alex", "Sam", "Jordan", "Riley"]

Print the list in reverse order using range() with a negative step, e.g. range(len(crew)-1, -1, -1). Expected output:

Riley
Jordan
Sam
Alex

Problem 7 — pair up two lists

Given:

motor_names = ["Left", "Right"]
motor_powers = [60, 75]

Loop through indices with range(len(motor_names)) and print paired info like "Left: 60". Expected output:

Left: 60
Right: 75
💡 Tip
range(len(a_list)) is the standard way to loop "by index" instead of by item — reach for it whenever you need the position number itself, or when you need to walk two equal-length lists side by side using the same index into each.
