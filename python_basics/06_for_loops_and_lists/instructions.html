Assignment 6: For Loops & Lists

⏱ Estimated time: 50 minutes Prerequisite: Assignment 5 — While Loops

Robots almost never deal with just one number at a time. A distance sensor might report readings 50 times a second. A path-following robot needs to remember a whole list of waypoints. A four-motor rover has four speeds to set, every cycle. Python's answer to "I have a bunch of related values" is the list — and its answer to "do something with each one" is the for loop. Together, they're the tools you'll use constantly once you start writing real robot code.

What you'll learn
  • What a list is and how to write one
  • How to access items in a list by index, including negative indices
  • How to find out how many items a list has with len()
  • How to loop over every item in a list with for item in a_list:
  • How to repeat something a fixed number of times with range()
  • How to build a list from scratch with .append()

Lists: a container for many values

So far, every variable you've made has held exactly one value: one number, one string. A list is a single variable that holds an ordered collection of values, written between square brackets [ ] and separated by commas.

sensor_readings = [22, 19, 31, 8, 40]

This is one variable, sensor_readings, holding five numbers in a specific order. Lists can hold numbers, strings, or a mix of both — Python doesn't require every item to be the same type, though in practice you'll usually keep a list to one kind of thing (like five distance readings, or four motor names).

Indexing: reaching into a list

Every item in a list has a position, called an index. Python starts counting indices at 0, not 1 — so the first item is at index 0, the second at index 1, and so on.

sensor_readings = [22, 19, 31, 8, 40]
print(sensor_readings[0])   # 22  (the first item)
print(sensor_readings[2])   # 31  (the third item)

You can also count from the end of the list using negative indices. -1 is always the last item, -2 is the second-to-last, and so on — no need to know how long the list is.

print(sensor_readings[-1])  # 40  (the last item)

len(): how many items?

The built-in function len() tells you how many items are in a list.

print(len(sensor_readings))  # 5

for item in a_list: — looping without a counter

With a while loop, you'd need a counter to step through a list: start it at 0, check it's less than len(), increment it, and index into the list each time. A for loop does all of that automatically — it hands you each item, one at a time, until the list runs out.

sensor_readings = [22, 19, 31, 8, 40]
for reading in sensor_readings:
    print(reading)

This prints all five numbers, one per line. Each time through the loop, the variable reading is set to the next item in the list — first 22, then 19, then 31, and so on. You can name that variable anything you like; it's just a label for "the current item." A for loop combines naturally with an if statement to act only on items that meet some condition, or with an accumulator variable to total up every item — exactly the patterns you'll practice below.

for i in range(n): — repeating a fixed number of times

Sometimes you don't have a list at all — you just want to repeat something a set number of times, like setting up four motors or blinking an LED ten times. The range() function generates a sequence of numbers for the for loop to step through.

for i in range(4):
    print(i)

This prints 0, 1, 2, 3 — four numbers total, starting at 0 and stopping before 4. In general, range(n) runs the loop n times, with i taking on 0, 1, ..., n-1. range() can also take a start and a step: range(2, 10, 2) counts 2, 4, 6, 8 — starting at 2, stopping before 10, jumping by 2 each time.

.append(): building a list inside a loop

You can start with an empty list, [], and grow it one item at a time using .append(value), which adds value onto the end of the list.

squares = []
for i in range(5):
    squares.append(i * i)
print(squares)   # [0, 1, 4, 9, 16]

This is a common pattern: start with an empty list, loop, and build it up — the list equivalent of the accumulator pattern you used with numbers in Assignment 5.

💡 Tip
If you only need the items themselves, use for item in a_list:. If you need to count, repeat a fixed number of times, or don't have a list yet, use for i in range(n):. Both are "for loops" — just pick whichever fits what you're actually looping over.
⚠️ Common mistake
Indices start at 0, not 1. For a 5-item list, the last valid index is 4, not 5 — trying to access sensor_readings[5] on a 5-item list crashes with IndexError: list index out of range. When in doubt, use -1 to safely grab the last item instead of guessing the length.
